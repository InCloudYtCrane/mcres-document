# 这是一个什么样的地方

MCRES 是一个非营利性的 Minecraft 玩家社区。

说它非营利，不是一句客套话。站点没有广告，没有付费内容，没有会员等级，也不接受任何形式的商业赞助。所有资源由社区成员自愿贡献，下载和使用完全免费。服务器和域名的开销由维护团队自行承担，他们不从中获取任何收入。

这里做的是一件简单的事：让玩 Minecraft 的人，有个地方能安心地找资源、聊游戏。

# 谁在维护它

维护 MCRES 的，是一支业余的志愿者团队，也是这个站点的开发者。

团队成员分散在各地，白天各有各的工作或学业，利用业余时间写代码、改功能、修bug。他们不是全职做这个，也没有报酬和合同约束，支撑他们的只是对这款游戏和这个社区的热爱。

站点的三个子系统——主站、选料、茶室——从功能设计到代码实现，都出自这支团队之手。他们既是开发者，也是运营者。写完了功能，还要自己审核用户提交的资源，处理举报与违规，撰写和更新文档，回应用户的疑问。这些工作大部分是重复的、琐碎的，且不被大多数用户看见。

# 这个社区靠什么运转

靠参与。

资源是用户提交的，评论是用户写的，讨论是用户发起的。维护团队搭好台子，唱戏的是所有人。一个社区能不能长久，不取决于它的功能有多齐全，而取决于有没有人愿意在这里留下点什么。

所以，如果你在这里找到了想要的东西，不妨也试着留下一点。写条评论告诉作者你用着觉得怎么样，发个帖子聊聊你的想法，或者在你熟悉的领域里帮别人解答一个问题。这些看起来很小的事，加起来就是这个社区的全部。

# 我们会尽力做好

需要承认的是，MCRES 并不完美。

志愿者的精力有限，审核和举报处理不一定及时。功能可能有 bug，文档可能有遗漏，遇到问题时的响应速度也比不上商业平台。这些我们清楚，也在慢慢改进。

如果遇到问题，欢迎反馈。反馈的时候尽量说清楚：你在哪个页面、做了什么操作、期望看到什么、实际发生了什么。信息越具体，处理起来越快。

也请对维护团队多一点耐心。他们和你一样，只是喜欢这个游戏的普通人。
