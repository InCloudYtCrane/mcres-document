# 嗨～欢迎来到 MCRES 呀！

MCRES 是一个非营利性的 Minecraft 玩家社区，由一群爱好者自发维护哒～

这里没有广告，没有付费墙，没有乱七八糟的会员制度哦。所有资源都是社区成员一起贡献的，运营成本由维护团队自己掏腰包捏。站点靠一群志愿者在业余时间撑着，图的就是让玩 Minecraft 的人有个能安心找资源、聊游戏的小窝呀。

站点目前由三个部分组成，共用同一个账号，登录一次就能在三处通行啦～ 你可以在任意一个地方玩，也可以三个都用哇。

# 主站——找资源的地方

主站是站点的主体，收录 Minecraft 的三类资源：资源包、光影包、地图。

想换材质、加光影、找张地图开新档，来这里翻就对啦～ 每份资源都有介绍、截图、版本信息，看中了直接下载，不用登录的哦。

登录之后还能点赞、收藏、投币、留评论，顺手支持一下喜欢的作者呀。

如果你自己也在做资源，可以往主站投稿捏。新资源或者修改已有资源都行，提交后会有志愿者审核哒。通过了就正式上架，没通过会给你发条消息说明原因，改一改重新提交就好啦～

# 选料——看看你的电脑能跑多少帧

选料是一个性能预测系统，帮你提前判断某个资源在你的电脑上大概能跑多少帧哇。

在选料主页填上自己的硬件配置，系统就会给你推荐你能玩的东西，并且附上预期帧率喔。这个就是选料区的职能哦～

不过预测再准也得有真实数据撑着呀。你可以在选料提交帧率投稿，说说自己用什么显卡... CPU、跑哪个资源、实测多少帧，顺手截个图或者录段视频嘛。投稿审核通过后会进入统计池，帮着把预测结果调得更准哒。

不想投稿也没关系，投票也行哇。看到预测结果，点一下"偏大""准确"或"偏小"，动动手指就能参与啦～

<del>这个模块怎么感觉这么潦草</del> 才不是呢，这个模块其实是开发者开发最认真的模块呢！

# 茶室——聊天灌水的地方

茶室是站内的社区论坛，日常聊游戏、问问题、找人组队、碎碎念，都在这里呀。

内容分话题和帖子两层哦。话题是大类，按活跃程度分不同档位。帖子是具体内容，可以发求助、分享、讨论、组队、碎念等不同类型哒～

你可以发帖、回复、关注感兴趣的话题捏。有些话题设了发帖门槛，需要先在茶室混一段时间、攒够等级才能在里面发言呀。等级由志愿者根据活跃情况授予，多在茶室冒泡自然就有啦。

碰到违规内容，举报按钮在每处都有哦，志愿者会来处理哒～

# 三个部分怎么配合

三个部分共用一份账号呀。在主站登录后，选料和茶室都会认出你，不需要反复登录捏。你在三个地方各有自己的角色和等级，互不影响哒。

三个部分的业务也彼此独立哦。主站管资源，选料管性能预测，茶室管社区聊天。你在哪个部分活跃都不影响其他地方的使用呀。

两部分之间有小小的联动哇：茶室里有些话题会关联到主站的资源或作者，在这些话题页能看到对应资源的信息；选料的投稿会引用主站的资源，用于把那份资源的性能数据算得更准捏～

# 这份文档怎么用

文档按功能组织哒，每章介绍一个部分，说明它有什么、你在里面能做什么、具体怎么操作呀。

想查某个功能怎么用，直接跳到对应章节就好啦～

第一次来 MCRES，建议先读完这一章，对整体有个印象，再按需深入哦。

文档没写到的细节，可以在站内搜索，或者直接在茶室发帖问嘛。涉及账号、审核、举报结果这类具体问题，通过站内消息联系志愿者就行啦～
