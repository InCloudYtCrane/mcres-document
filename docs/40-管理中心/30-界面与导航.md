# 侧边栏
后台的一切入口都在左侧边栏。窄屏下侧边栏会收缩为纯图标，点击图标同样能展开对应模块。

侧边栏顶部是你的账号信息，从上到下依次是头像、昵称、三行角色标签。三行分别是主站用户组、选料用户组、茶室用户组。角色标签的当前值以颜色区分级别，未达到后台门槛的角色会显示为灰色。

账号信息下方是搜索框，输入后回车会跳转到主站的搜索页，用于快速查看站内资源。搜索框带补全，输入关键词会提示匹配的资源名和用户名，未输入时显示你的历史搜索记录。补全数据来自主站，与后台自身的审核数据无关。

# 菜单组织
菜单分三个顶层模块：主站、选料、茶室。

每个模块标题左侧带一个图标，右侧带一个数字，表示该模块当前对你可见的菜单项数量。模块整体可折叠，点击标题即可展开或收起。

模块内部按角色分组。以主站为例，工坊工匠、精英工匠、工坊主管各自对应一组菜单，高于你角色的组不会显示，低于你角色的组会显示但你未必用得着。分组标题前带一个小图标，与菜单项图标区分开。

某些菜单项下面是可折叠的子项，例如主站主管组里的「统计数据」，展开后是流量统计与操作日志。这类子项在折叠状态只占一行，展开后才露出下级。

当前页面对应的菜单项会高亮，左侧带一条彩色竖线，颜色对应该模块的主色。同时，当前页所在的顶层模块会自动展开。

# 折叠状态与滚动位置
侧边栏的折叠状态和滚动位置在同一个浏览器会话内保留。你展开了哪些模块、侧边栏滚动到了哪里，刷新页面后不会丢失。关闭浏览器后这些状态清空。

# 退出后台
侧边栏顶部或页头右侧通常有「退出后台」入口。点击后返回主站首页，账号本身不登出。需要真正登出时，去主站执行登出操作。

工坊主管在模拟状态下，页面顶部会出现一条醒目提示，附带「退出模拟」按钮。点它还原为原管理员身份，不会跳转离开后台。

# 主内容区
右侧是主内容区，每个页面结构基本一致。

页面顶部是页头，包含页面标题和一行副标题。副标题通常显示当前角色、数据总量或简要说明。

页头下方是面包屑，显示当前页在功能层级中的位置。面包屑的每一级都可点击，用于快速回到上级。

内容区主要由卡片构成。列表类页面是一张带表头和分页的表格卡片；详情类页面由多张信息卡片纵向排列；设置类页面是一张表单卡片。

表格支持分页、排序与筛选，筛选条件通常放在表格上方。部分列表还支持批量选择，勾选后表格上方会出现批量操作栏。

# 常见交互
模态框用于处理需要二次确认或补充信息的操作。填写完点击确认提交，点取消或遮罩关闭，按 ESC 同样关闭。提交过程中按钮会变为加载状态，成功后自动关闭并刷新列表，失败则保留内容供修改。

Toast 用于提示操作结果，从页面顶部或底部短暂出现，自动消失。成功为绿色，失败为红色，警告为黄色。

图片类内容支持点击放大。审核详情页的截图、图片管理里的缩略图都可点开查看原图，按 ESC 或点击空白处关闭。

# 错误页面
后台的 403、404、500 页面独立设计，与主站风格不同。

403 是权限不足，通常意味着你的角色级别不够，或所访问的资源不在你的管辖区内。若确认应该能访问，联系工坊主管核对角色配置。

404 是页面不存在，通常发生在链接拼写错误，或所访问的审核记录、资源记录已被删除。

500 是服务器内部错误，重新加载通常能恢复。若持续出现，把当前页面路径和操作步骤反馈给工坊主管，便于定位。
