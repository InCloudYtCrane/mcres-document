# 这一块覆盖什么

选料模块处理的是资源性能数据的采集、审核与建模。用户提交真实帧率投稿和测评文章，经过审核进入数据库，后台据此计算资源的基准帧和校准因子，供主站的性能预测功能调用。

按角色分层大致如下。

甄料师能用的是选料审核工作台，以及在自己编辑管辖区内查看和修改资源基准。

掌料人在甄料师基础上，审核不再受辖区限制，全站资源可查可改，同时开放硬件库和 MC 百科映射。

料总管在掌料人基础上，增加批量导入、批量删除，以及选料权限分配。

未分配和试料员进不了选料后台。

选料角色的调整有两处入口。一是选料模块的选料权限页面，由料总管操作，能同时配置角色和两套管辖区。二是用户管理页面里每个用户的选料角色下拉框，由工坊主管操作，只能改角色本身。
