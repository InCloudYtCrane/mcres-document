图片管理用来浏览和维护 img.mcresource.cn 上的图片资源。主站资源封面、截图、头像、授权图、纹理预览等都存在这个图片服务上，图片管理是唯一能在后台直接操作这些文件的地方。

入口在侧边栏「图片管理」，路径 `/3_img`。

精英工匠及以上能进入浏览。上传和删除仅对工坊主管开放，精英工匠只读。

![](https://img.mcresource.cn/help/15_20260925_183329.jpg)

# 整体布局
页面顶部是路径面包屑，显示当前所在的目录。初始位于根目录，显示为 `/`。

面包屑下方是工具栏。左侧有「上级目录」按钮和搜索框，右侧显示当前目录下的项目总数。「上级目录」在根目录时隐藏。

再下方是文件卡片，里面是一张表格，列出当前目录下的文件夹和图片。

# 目录结构
图片服务按业务划分了几类目录，常见的包括资源封面、资源截图、用户头像、授权图、资源包纹理预览等。这些目录由各业务模块自动写入，一般不手动创建。

浏览时，文件夹以黄色图标显示，点击进入。图片以缩略图显示，同时显示文件名、文件大小、修改时间。

表格顶部不显示单独的分页控件。图片较多时，表格底部会出现「加载更多」按钮，每次加载 20 张，直到全部加载完。

# 搜索
搜索框按文件名模糊匹配，作用范围是当前目录。输入即过滤，不会递归到子目录。

搜索状态下「加载更多」同样可用，分页基于过滤后的结果。

# 预览图片
点击缩略图或操作列的预览按钮，弹出预览模态框。

![](https://img.mcresource.cn/help/16_20260925_183354.jpg)

预览模态框显示原图，下方是图片的完整 URL，右侧有两个按钮。「复制」把 URL 复制到剪贴板。「切换相对/绝对」在完整 URL 和相对路径之间切换，方便在代码里使用。

点模态框外的空白区域或按 ESC 关闭。

# 上传图片
工坊主管在浏览某目录时，可以点工具栏的「上传图片到当前目录」按钮上传。

上传前浏览器会压缩图片到最长边不超过 1200 像素，JPEG 质量 0.85。超过这个尺寸的图片会明显变小，适合站点使用。

选择文件后立即上传，不需要二次确认。上传完成后当前目录刷新，新图片出现在列表中。

上传的文件类型限于常见图片格式。选择非图片文件时上传会被拒绝。

# 删除图片
工坊主管在图片列表点击删除按钮，二次确认后删除。

删除是不可恢复的。如果有主站资源正在引用这张图片，主站的引用会失效，页面上的图片会显示为破图。删之前应确认没有资源正在使用。

# 复制链接
图片列表的操作列有一个复制按钮，点它把图片的完整 URL 复制到剪贴板。

从预览模态框复制的链接格式与此一致。

# 图片服务的写入来源
图片管理只负责浏览和手动维护，大部分图片不是在这里上传的，而是由各业务模块在处理提交时自动写入图片服务。

用户编辑审核通过时，提交内容里的封面、截图、纹理预览会被上传。

用户在用户管理里改头像时，头像会被上传。

资源包预览管理上传纹理时，纹理图片会被上传。

文件管理里设置授权图时，授权图会被上传。

这些写入的图片与手动上传的图片存储方式一致，都出现在对应的目录下，可以在这里统一浏览和清理。
