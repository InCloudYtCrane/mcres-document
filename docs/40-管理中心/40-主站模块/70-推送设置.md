推送设置用来配置主站首页展示的内容，包括轮播图、热门推荐、最新推荐和公告。入口在侧边栏「推送设置」，路径 `/4_ps`。

仅工坊主管可访问。

# 整体布局

![](https://img.mcresource.cn/help/24_20260925_192526.jpg)

页面顶部是统计卡片，显示轮播图、热门推荐、最新推荐、公告的当前条目数。

下方按四个板块纵向排列，依次是海报轮播管理、热门推荐管理、最新推荐管理、公告管理。每个板块是一张独立卡片，卡片头部有标题、条目计数和操作按钮。

# 首页内容的生效方式

本页面保存的内容会立即反映到主站首页。轮播图和公告没有缓存，保存后刷新主站首页即可看到变化。热门推荐和最新推荐如果开启了自动更新，则以算法挑选的结果为准，手动列表作为兜底。

# 轮播图

轮播图是首页顶部横向切换的大图区域。

每条轮播包含以下字段。

标题显示在图片上方或下方，是必填项。

描述是可选的一行补充说明，通常用来写一句话简介。

元信息是可选的一行小字，常用来标注作者、版本或更新时间。

标签是右上角的角标文字，可以写成「推荐」「新」这类简短词。

封面 URL 是图片直链，建议先用图片管理上传，再复制链接填进来。为空时该条轮播会显示占位图标。

跳转链接是点击轮播后跳转的目标地址。可以是主站资源页的相对路径，也可以是任意外部链接。留空时默认跳 `#`，不产生跳转。

轮播图以卡片网格排列，每条卡片右上角有一个拖拽手柄用于排序，卡片下方有编辑和删除按钮，以及上移、下移按钮。列表顶部和底部的条目对应的上移或下移按钮不可用。

排序的先后决定主站首页的轮播顺序。

# 热门推荐与最新推荐

热门推荐和最新推荐的结构一致，配置方式也一致，只是展示在主站首页的不同区块。

每条推荐只包含两个字段。

资源类型从资源包、光影包、地图三项中选择。

资源 ID 是对应资源的数字 ID。填写时不需要知道资源名或封面，保存后后端会自动按类型和 ID 查出名称和封面，一并写入。

同一个资源不能重复添加。若尝试添加一个已在列表中的资源，会弹出提示并拒绝。

这两个列表以表格形式呈现，每行显示序号、资源名、类型、资源 ID、封面缩略图和操作按钮。操作包含移除和上移、下移。

名称或封面缺失时，列表显示占位内容。这一般意味着填写的资源 ID 在对应类型下不存在，需要核对后修正。

# 自动更新开关

热门推荐和最新推荐各有一个自动更新开关，位于各自板块的卡片头部。

开关关闭时，主站首页展示的就是这两个列表里的内容，顺序与列表中一致。

开关打开时，主站首页展示的内容由后台算法按资源的热度或上架时间自动挑选，列表内容仅作为兜底。切换开关后立即生效，主站首页刷新即可看到变化。

自动更新与手动列表不冲突。开关关闭后列表内容重新生效，不需要额外配置。

# 公告

公告显示在主站首页的显眼位置，通常用于站务通知或活动说明。

每条公告包含以下字段。

标题是公告的简短标题，必填。

内容是公告正文，可以是多行文字。

发布时间是该条公告的展示时间，格式为字符串，通常写日期，例如 `2026-09-18`。这个字段仅用于显示，不影响公告的生效时间。

公告以表格形式列出，每行显示序号、标题、内容摘要、发布时间和操作按钮。操作包含编辑和删除。

新增公告保存后，系统会向全部用户发送一条站内消息，内容为公告标题和正文。这是唯一会自动群发消息的模块。若只是想调整已有公告的措辞，用编辑而不是删除后新增，后者会再次触发群发。

# 编辑与新增

四个板块的新增和编辑都通过同一套模态框完成。

点「添加」或「编辑」按钮打开模态框，模态框内的字段随板块不同而变化。填写完成后点「保存」，内容会立即写入后台并在主站生效。

模态框内点「取消」或按 ESC 关闭，所有未保存的改动丢失。

# 数据保存机制

每次修改都会立即提交给后台，不依赖页面级的保存按钮。也就是说，添加一条轮播后马上刷新页面，内容不会丢失。

后台保存的是整份推送配置，包含四个列表和两个自动更新开关。每次提交都覆盖整份配置，因此多个管理员同时编辑时以最后一次保存为准。

多人协作时建议错开操作，避免相互覆盖。

# 前端只提交必要字段

热门推荐和最新推荐在提交时只发送资源类型和资源 ID，名称和封面由后端补全。因此即使列表显示的名称是旧的或缺失，只要保存的 ID 正确，主站展示的内容就是正确的。

若发现主站展示的名称与自己看到的不一致，通常是资源的名称在主站被修改过，而本页面的列表还停留在旧数据。刷新本页面即可同步。
