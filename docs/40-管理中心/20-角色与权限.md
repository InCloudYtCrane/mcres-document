你在后台能做什么，由三样东西决定：你的主站角色、你的选料和茶室角色、你的管辖区。三者互不覆盖，各管一块。

# 主站角色
主站角色是进入后台的门槛，也是主站模块的权限来源，存在 `user_info.role` 里。

工坊工匠（2）是辖区运营。你能审用户编辑，能管资源文件，但只在你的管辖区内。辖区外的资源在后台不可见，也无法操作。图片管理、资源包预览、举报与封禁这三个模块不向你开放。

![](https://img.mcresource.cn/help/2_20260925_181016.jpg)

精英工匠（3）是全站运营。审核和文件管理不再受辖区限制，可管理全站资源，上述三个模块也会开放。用户管理这块仍不开放，你能做的最多是对目标用户执行封禁，不能修改角色。

![](https://img.mcresource.cn/help/3_20260925_181052.jpg)

工坊主管（4）是全局管理。用户管理、推送设置、站内规则管理、流量统计、操作日志这几个主管专属模块全部开放，还可以任免其他账号的主站角色，以及使用模拟功能。

![](https://img.mcresource.cn/help/4_20260925_181205.jpg)

# 选料角色
选料角色与主站角色相互独立，存在 `user_info.sel_role` 里，是选料模块的权限来源。

甄料师（2）可进入选料审核台，审核范围受选料审核管辖区限制。修改资源基准的权限受选料编辑管辖区限制。

![](https://img.mcresource.cn/help/5_20260925_181233.jpg)

掌料人（3）不受辖区限制，全站资源可查看、可修改。资源基准、校准因子、硬件库、MC 百科映射均在其操作范围内。

![](https://img.mcresource.cn/help/6_20260925_181407.jpg)

料总管（4）在掌料人基础上增加批量导入、批量删除，以及为其他账号分配选料角色的权限。

![](https://img.mcresource.cn/help/7_20260925_181439.jpg)

未分配（0）与试料员（1）不具备选料后台的访问权限。

# 茶室角色
茶室角色同样独立，存在 `user_info.tea_role` 里，是茶室模块的权限来源。

茶博士（3）是茶室日常管理角色，可访问话题管理、帖子管理、举报中心、用户列表与批量处罚。

![](https://img.mcresource.cn/help/8_20260925_181453.jpg)

馆主（4）在茶博士基础上增加策展台的全部功能：雅间管理、柜台管理、今日茶话、全局置顶、话题绑定，以及任命茶友、茶博士、堂主、护法。

![](https://img.mcresource.cn/help/10_20260925_181522.jpg)

茶友（2）及以下不具备茶室后台访问权限。

# 管辖区
管辖区是给**「工坊工匠」**和**「甄料师」**划定的操作边界，只对这两个角色生效。

管辖区分三类，分别对应不同的操作：

编辑区（`edit_area`）决定你免审核编辑时可以操作哪些资源。

审核区（`review_area`）决定你可以审核哪些资源下的用户编辑或选料投稿。

文件区（`file_area`）决定你可以管理哪些资源的文件，包括上传、重命名、删除与排序。

每类管辖区按资源包、光影包、地图三个类目划分，每个类目可设为"全部"或指定一组 ID。设为全部表示类目内所有资源都在范围内，设为 ID 列表表示仅列表内的资源在范围内，未列出的类目视为无权限。

选料模块另有两套独立管辖区，存于 `sel_edit_area` 与 `sel_review_area`，结构与主站一致，额外支持整合包与模组两个类目。主站的管辖区不会影响选料，反之亦然。

管辖区由工坊主管在用户管理页面配置。

# 菜单与权限的关系
侧边栏依据主站角色、选料角色、茶室角色综合裁剪，某个菜单项不可见，意味着对应角色的级别不足，或该模块与你的账号所属子系统不适用。

管辖区不参与菜单的显示判定。工坊工匠即使管辖区为空，审核与文件管理的菜单依然存在，只是页面内不显示任何可操作项。

# 模拟身份
工坊主管可对任意账号执行模拟，临时以该账号的身份访问后台。模拟期间页面顶部显示明显提示，所有操作以目标账号的身份记入审计日志。

模拟会记录起止时间、目标账号与操作 IP。模拟状态下会话中的管理员标识不丢失，退出模拟后恢复为原管理员身份。模拟存在有效期，超时后自动退出。
