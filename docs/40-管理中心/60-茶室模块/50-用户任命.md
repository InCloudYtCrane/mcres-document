用户任命分两个页面，分别管理茶室角色和话题管理员。

茶友和茶博士的任命在「任命茶友/茶博士」页面，路径 `/tea/user/role`。

堂主和护法的任命在「任命堂主/护法」页面，路径 `/tea/user/manager`。

两个页面都仅对馆主开放。

# 茶室角色的层级

茶室角色分四档：茶客、茶友、茶博士、馆主。

茶客是进入茶室的默认角色，注册后自动获得。

茶友比茶客多了部分话题的发言权限，也能在部分受门槛保护的话题里发帖。茶友的名额通常有限，任命时需要斟酌。

茶博士是茶室的日常管理角色，能进入茶室后台，处理话题、帖子、举报、处罚等事务。

馆主是茶室的最高角色，在茶博士基础上增加策展台和用户任命的权限。

角色逐级放开权限。低角色无法执行高角色的操作，但高角色自动拥有低角色的所有权限。

# 任命茶友与茶博士

进入「任命茶友/茶博士」页面，列表显示所有茶室角色在茶客及以上的用户，按角色从高到低排列。

每行显示用户 ID、头像、昵称、最后活跃时间和当前的茶室角色下拉框。

顶部有搜索框，按昵称或用户 ID 过滤。

调整某个用户的角色时，直接在该行的下拉框中选择目标角色，然后点行末的「保存」按钮。

保存前会弹出确认框，显示从当前角色到目标角色的变更内容。确认后立即生效。

操作者不能修改自己的茶室角色。自己所在的行下拉框和保存按钮都置为不可用，旁边带一个「自己」标记。这样设计是为了避免馆主误操作把自己降级，导致无人能管理茶室。

角色变更不发送系统消息，用户不会收到通知。若需告知，另行通过其他渠道联系。

# 任命堂主与护法

堂主和护法是话题级别的管理员角色，不是全局角色。

堂主（owner）是话题的负责人，一个话题最多只有一位。堂主对话题内的帖子有管理权限，能置顶、加精、锁帖、删除。

护法（mod）是话题的协助管理员，一个话题可以有多位。护法的权限范围与堂主相同，区别在于堂主具有话题的唯一性。

堂主和护法只在该话题内生效，不影响其他话题。

进入「任命堂主/护法」页面，列表按话题 ID 升序排列，同一话题内堂主排在护法前面。

每行显示话题 ID、话题名、当前角色、用户昵称和头像。行末有「撤销」按钮。

页面右上角有「新增任命」按钮，用于创建新的堂主或护法。

# 新增任命

点「新增任命」按钮打开模态框，包含三个字段。

话题字段是一个搜索框。输入话题名或 ID 后，下方显示匹配结果，点结果选中目标话题。选中的话题以标签形式显示在搜索框下方。

用户字段同样是一个搜索框，输入昵称或 ID 后，下方显示匹配结果，点结果选中目标用户。

角色字段在两个选项之间单选：堂主和护法。默认选中堂主。

确认任命时，后台做以下检查。

话题必须存在且未封座。

用户必须存在。

若角色为堂主，该话题当前不能已有堂主。已有堂主时拒绝任命，需要先撤销现有堂主。

若该用户已经是该话题的护法，且本次任命的是堂主，会把该用户从护法升级为堂主。若已是堂主，重复任命同一角色会被拒绝。

确认后立即生效，无需额外保存。

# 撤销任命

在列表中点击某行的「撤销」按钮，二次确认后撤销该用户的堂主或护法身份。

撤销后该用户在该话题内不再具有管理权限，但不影响其在其他话题的管理身份，也不影响其全局茶室角色。

# 任命的实际效果

堂主和护法在前台的表现是话题页顶部的管理入口。拥有这两个身份的用户进入自己所管理的话题时，会看到额外的管理按钮。

被任命为堂主或护法的用户，其茶室角色不因此改变。茶客也能被任命为某个话题的堂主，只要获得该话题的授权。茶室角色和话题管理员身份是两条独立的授权路径。

因此若你希望某位用户能管理多个话题，可以逐个话题任命其为堂主或护法，而不必将其茶室角色升为茶博士。反之，若希望其能管理全站茶室事务，则需要将其茶室角色提升到茶博士或以上。

两种方式的区别在于作用范围和操作自由度。话题管理员只在被授权的话题内生效，权限被严格限定在话题内部。茶博士以上的角色在全站生效，不受话题边界的限制。
