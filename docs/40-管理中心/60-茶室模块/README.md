# 这一块覆盖什么

茶室模块处理的是 tea.mcresource.cn 社区板块的日常运营，包括话题与帖子的批量管理、举报处理、用户处罚，以及馆主专属的策展功能。

按角色分层大致如下。

茶博士能用的是话题管理、帖子管理、举报中心、用户列表、批量处罚。

馆主在茶博士基础上，增加策展台的全部功能，包括雅间管理、柜台管理、今日茶话、全局置顶、话题绑定，以及用户任命中的茶友与茶博士任命、堂主与护法任命，还有全局公告。

茶友及以下进不了茶室后台。

茶室角色的调整有两处入口。一是茶室模块的用户任命页面，由馆主操作，能任命茶友、茶博士、堂主、护法。二是用户管理页面里每个用户的茶室角色下拉框，由工坊主管操作。两处修改都会生效，以最后一次保存为准。

进入茶室后台的前提是主站角色达到工坊工匠或以上。主站角色不足时，茶室角色的分配不会生效。
