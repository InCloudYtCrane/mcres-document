帖子管理用来批量维护茶室的帖子，包括置顶、加精、锁定、移动、删除与恢复。入口在侧边栏「茶室」下的「帖子管理」，路径 `/tea/post`。

茶博士及以上能进入。

# 整体布局

页面顶部是页头，显示帖子总数。

下方是筛选栏，包含状态、类型、话题 ID、作者 ID 四个筛选项和一个搜索框。

再往下是批量操作栏。默认灰色不可用，勾选帖子后激活，并根据当前状态显示不同的操作按钮。

最下方是帖子列表表格，包含分页。

# 筛选

状态下拉可选正常、已删、全部。默认正常，也就是仅展示未删除的帖子。

类型下拉可选全部和六种帖子类型：求助、分享、讨论、组队、碎念、系统。类型由发帖者在发帖时选择。

话题 ID 输入框按话题 ID 精确过滤，用于只看某个话题下的帖子。

作者 ID 输入框按发帖人的用户 ID 精确过滤。

搜索框按标题或正文内容模糊匹配。

筛选条件通过表单提交，URL 参数保留。

# 列表

列表按帖子 ID 倒序排列，每行显示以下内容。

第一列是多选框，用于批量操作。

ID 是帖子的主键。

标题一列显示帖子标题，点击在主站对应帖子页打开。标题下方有一组标记徽章，可能出现的标记有已删除、公告、置顶、精华、已锁。公告是全局置顶，置顶是话题内置顶，精华是加精，已锁表示帖子禁止回复。

话题一列显示帖子所属话题，点击跳转到该话题页。

作者一列显示发帖人昵称，点击跳转到该用户的茶室主页。

类型显示帖子类型标签。

数据一列显示浏览量和回复数。

时间显示帖子的创建时间。

# 批量操作

勾选帖子后，批量操作栏激活。可用的操作根据当前筛选的状态不同而不同。

在正常状态下，可用的操作有：置顶、取消顶、加精、取消精、锁定、解锁、移动、删除。

在已删状态下，可用的操作只有恢复。

单次批量操作最多处理 100 篇帖子。

# 置顶与取消顶

置顶把选中的帖子在所属话题内置顶。话题内可以有多个置顶帖，按置顶时间倒序排列。

取消顶把选中的帖子从话题内置顶列表移除。

置顶与全局置顶不同。全局置顶需要柜台话题，在策展台的全局置顶页面配置。

# 加精与取消精

加精把选中的帖子标记为精华帖。精华帖在话题列表中显示特殊标记，通常用于标注质量较高的内容。

取消精把选中的帖子从精华列表移除。

# 锁定与解锁

锁定把选中的帖子设为禁止回复。用户可以看到帖子内容，但发帖框被隐藏。

解锁恢复帖子的正常回复功能。

# 移动

移动把选中的帖子迁移到另一个话题下。源话题的帖子数减，目标话题的帖子数加。

点「移动」按钮打开模态框，模态框内是一个话题搜索框。

输入话题名或 slug 后，下方显示匹配结果，点击结果选中目标话题。

选中的目标话题以标签形式显示在搜索框下方，带移除按钮。

目标话题不能是封座状态。已封座的话题不出现在搜索结果里。

点「确认移动」执行迁移。执行完成后，源话题和目标话题的计数同步更新。

# 删除与恢复

删除把选中的帖子标记为已删除状态，同时从所属话题的帖子计数中减去。帖子内容保留在数据库中，可通过恢复到正常状态。

恢复把已删除的帖子重新标记为正常，并重新计入所属话题的帖子计数。

删除操作不区分是作者自删还是管理员删除。管理员执行删除和恢复的效果与作者自删一致。

# 分页

列表底部分页，每页 30 条。

翻页时筛选条件保留，只有页码变化。
