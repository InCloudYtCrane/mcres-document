# 定位
MCRES 管理中心是 mcresource.cn 的运营后台，承担资源上架审核、文件与图片维护、用户权限与封禁管理、站内规则与推送配置，以及流量与操作日志审计等职责。该系统面向具备相应权限的运营人员，不面向普通用户开放。

管理中心并非单一功能产品，而是一套以权限为驱动的工具集。可见范围与可执行操作由账号所处的角色体系及管辖区共同决定。

# 准入条件
主站角色达到**「工坊工匠」**的账号方可进入管理中心。低于该门槛的账号访问任何后台页面均返回 403。

进入后台后，权限按主站角色逐级放开：

| 角色 | 定位 | 典型能力 |
| --- | --- | --- |
| 工坊成员（1） | 普通用户 | 无后台访问权限 |
| 工坊工匠（2） | 辖区运营 | 审核辖区内用户编辑；管理辖区内资源文件 |
| 精英工匠（3） | 全站运营 | 图片管理、资源包预览、举报与封禁 |
| 工坊主管（4） | 全局管理 | 用户管理、推送设置、站内规则、流量统计、操作日志 |


管理中心首页提供完整的权限对照表，当前账号所属角色列会高亮显示。

# 三套并行的角色体系
管理中心横跨三个子系统，账号在其中分别对应不同的角色。

**主站角色**（role）是进入后台的基础门槛，决定主站相关模块的可操作范围。

**选料角色**（sel_role）取值为 1 至 4，分别为试料员、甄料师、掌料人、料总管，决定在选料模块的审核范围、资源基准修改权限以及硬件库管理权限。

**茶室角色**（tea_role）取值为 1 至 4，分别为茶客、茶友、茶博士、馆主，决定在茶室模块的日常管理与策展权限。

三套角色相互独立，不存在继承或覆盖关系。同一账号在主站为工坊主管，其选料或茶室角色可能仍为未分配状态。实际可执行的操作以侧边栏中可访问的菜单项为准。

# 业务划分
侧边栏按业务将功能划分为三个模块。

**主站模块**涵盖资源审核、文件管理、图片管理、资源包预览、举报与封禁，以及仅对工坊主管开放的用户管理、推送设置、站内规则管理、流量统计与操作日志。

**选料模块**涵盖帧率投稿与测评文章的审核、资源基准与校准、硬件库管理、MC 百科映射管理，以及选料权限分配。

**茶室模块**涵盖话题与帖子的批量管理、举报中心、用户处罚，以及仅对馆主开放的策展功能，包括雅间管理、柜台管理、今日茶话、全局置顶与话题绑定。

菜单项依据账号的角色与权限自动裁剪。若某模块不可见，通常表示当前角色不具备访问权限，而非页面异常。

# 登录与会话
后台部署于 admin 子域。未登录状态下访问任意后台页面会跳转至主站登录页。登录状态通过 `.mcresource.cn` 域的会话 Cookie 在主站与各子域之间共享，无需重复登录。

后台的退出操作仅返回主站，不注销账号登录状态。

工坊主管可使用模拟功能，临时以指定用户的身份执行操作。模拟期间页面顶部显示明显提示，操作记录会计入审计日志，可随时通过退出模拟还原为原管理员身份。

# 指南结构
本指南后续章节将依次介绍角色与权限的细节、界面与导航的说明，并逐模块展开各页面的功能与注意事项。若仅需了解某一具体操作，可直接跳转至对应模块章节。

指南未覆盖的问题，可咨询当前在线的工坊主管，或在操作日志中检索近期同类操作记录作为参考。
