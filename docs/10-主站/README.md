# 这是什么

> 主站是站点的主体，收录 Minecraft 的三类资源：资源包、光影包、地图。<sup>[[1]](https://help.mcresource.cn/#_1)</sup>

[方块工坊（MCRES）主站](https://www.mcresource.cn/)是 Minecraft 资源的收录、展示与下载平台，也是连接工坊内其它部分的主要通道。主要承载以下功能：

- Minecraft 资源浏览与检索
- 资源详情展示与下载
- 资源投稿与审核
- 用户注册、登录与个人中心
- 用户之间、用户与工坊之间的互动
- 其它相关功能
