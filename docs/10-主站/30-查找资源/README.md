# 查找资源

本目录介绍在主站内查找资源的方式，包括浏览、检索、查看详情与下载资源。

## 本目录包含

- [浏览与检索](/10-主站/30-查找资源/10-浏览与检索)：介绍资源分类、浏览资源、检索资源、资源列表页与搜索结果页。
- [详情与下载](/10-主站/30-查找资源/20-详情与下载)：介绍资源详情页、下载页面、资源包预览、光影包预设与编辑历史对比。

## 推荐阅读顺序

1. 先阅读[浏览与检索](/10-主站/30-查找资源/10-浏览与检索)，了解如何找到资源。
2. 再阅读[详情与下载](/10-主站/30-查找资源/20-详情与下载)，了解如何查看和下载资源。

## 快速开始

- 从主页推送横幅或资源分类展示区开始浏览。
- 使用顶部搜索框检索资源。
- 点击资源卡片进入详情页，按需下载。

## 与其它模块的关系

- 本目录仅涵盖主站内查找资源的方式。
- 关于账号注册登录，请查阅[账号与登录](/10-主站/10-开始使用/20-账号与登录)。
- 关于资源投稿，请查阅[投稿资源](/10-主站/40-投稿资源)。
- 选料、茶室等独立模块不在本目录范围。
