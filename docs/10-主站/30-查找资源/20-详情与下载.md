# 关于本页的说明

本页介绍资源详情页及其相关子页面的结构与功能，包括三类资源（资源包、光影包、地图）的详情界面、光影包预设、编辑历史对比与资源包预览。关于如何找到这些资源，请参阅[浏览与检索](/10-主站/30-查找资源/10-浏览与检索)。

本文档不负责告知如何安装和使用这些资源。关于安装与使用，请查阅更全面的说明或百科，这里推荐相关网站：[Minecraft Wiki](https://zh.minecraft.wiki/)。但请注意：本站无法保证外部网站的安全性和可靠性，请谨慎甄别。

# 资源详情页

## 页面概述

资源详情页是展示单个资源完整信息、提供下载入口的核心页面。点击资源列表页、搜索结果页或主页资源卡片中的任意一项，即可进入对应的资源详情页。

![资源详情仿真](https://img.mcresource.cn/help/jpg_20261006_125358.jpg)
<div style="text-align:center; font-size:0.85em; color:#666; margin-top:6px;">该界面为仿真界面，将三个界面合并以节省版面，非实际截图，请以实际为准</div>

三类资源的详情页结构基本一致，但各自有专属的信息板块：

| 资源类型 | 特有板块 | 下载方式 |
| :---: | :---: | :---: |
| 资源包 | 资源包预览 | 内部下载或外部链接 |
| 光影包 | 光影包预设 | 内部下载或外部链接 |
| 地图 | 无 | 内部下载或外部链接 |

整个页面大致分为**顶部媒体区**、**左侧信息栏**和**右侧内容区**三大部分。

## 顶部媒体区

页面顶部展示资源的媒体内容，用于直观呈现资源效果。

### 封面与截图

- **封面**：左侧大幅预览图。
- **截图**：右侧横向排列的缩略图，左上角显示截图总数。
- 点击任意截图可查看大图，点击任意处关闭大图。
- 截图中的视频为内嵌哔哩哔哩播放器，点击可播放。

### 操作按钮

- **分享**：复制或分享当前资源页面。
- **编辑此页面**：进入资源编辑界面。

## 左侧信息栏

左侧信息栏展示资源的基本属性、数据统计与下载入口，自上而下包含以下内容。

### 标题与状态

- **状态标签**：如“活跃”“半弃坑”“停更”等。
- **资源名称**：资源的主名称。
- **副标题**：资源次要名称。

### 作者与评分

- **作者**：显示作者名称，若作者是工坊成员，则点击可进入作者个人主页。
- **评分**：星级评价与评分数值。

### 数据统计

- **相对比值**：与全站平均值的对比。
- **昨日平均**：昨日平均浏览数据。
- **今日浏览 / 昨日指数 / 总浏览量**：三宫格数据。
- **收录时间**：资源被收录的日期。

### 浏览趋势

以折线图形式展示资源近期浏览量的变化趋势，包含“本资源”与“全站平均”两条曲线。右上角可切换时间范围（如“近30天”）。

### 资源属性

按资源类型不同，展示的属性字段有所差异。

### 下载入口

根据资源是否已设置授权图片，下载入口有两种形式：

- **外部链接下载**：当项目尚未设置授权图片时，显示黄色提示“请使用外部链接下载”，外部链接在资源属性的最后一个字段提供。
- **内部下载**：当项目已设置授权图片时，显示按钮 `下载此XXX`，点击后进入下载界面，详见*下载页面*。

按钮下方通常会显示协议说明（如“已遵循协议开放下载”）与“编辑历史对比（查看所有版本）”入口。

## 右侧内容区

右侧主内容区展示资源的详细介绍与用户互动。

### 资源介绍

以图文形式展示资源的详细说明，包括概述、风格、注意事项等。

### 资源包预览

仅在资源包详情页显示，且**仅当当前资源包已添加预览内容时显示**。若资源包未添加预览内容，则该板块不显示。

点击 `查看预览` 按钮可进入资源包预览页面，详见*资源包预览*。

### 光影包预设

仅在光影包详情页显示，**即使当前光影包没有添加预设也会显示该板块**，因为这不仅是查看预设的入口，也是投稿预设的入口。

点击 `查看预览` 按钮可进入光影包预设页面，详见*光影包预设*。

### 看法

用户可在该区域发表对资源的看法与评论。

- **输入框**：最多 500 字。
- **发表看法**：点击绿色按钮提交。
- **看法列表**：展示已有评论。若暂无评论，显示“还没有看法，来发表第一条吧！”

# 下载页面

当资源已获授权并支持内部下载时，点击详情页的下载按钮进入下载页面。

本章节仅介绍工坊内部的下载页面和内部下载方式。关于外部下载，请查阅相关说明或文档。

## 页面概述

下载页面用于集中展示该资源可下载的所有文件版本，并提供筛选与下载入口。

- **资源名称与作者**：页面顶部显示资源名称与作者名。
- **安全提示**：页面顶部提示“本站保证文件内容未经篡改，请放心下载”与“所有文件均提供哈希校验，确保完整性”。
- **授权状态**：页面中央显示项目授权图与“已获授权，可下载”提示。

## 筛选栏

页面上方提供筛选控件：

- **文件版本**：下拉选择，可按文件版本号筛选。
- **游戏版本**：下拉选择，可按游戏版本筛选。
- **清除筛选**：重置所有筛选条件。
- **文件总数**：显示当前筛选条件下的文件数量。

## 文件列表

文件列表以表格形式展示，包含以下列：

| 列名 | 说明 |
| :---: | :---: |
| **文件名** | 无 |
| **版本** | 无 |
| **游戏版本** | 支持的游戏版本范围。 |
| **下载次数** | 该文件的累计下载次数。 |
| **修改时间** | 文件最后修改时间。 |
| **文件大小** | 无 |
| **操作** | `下载` 按钮。 |

点击任意一行的 `下载` 按钮，将弹出验证码状态框。

## 验证码状态框

点击下载按钮后，弹出验证码状态框，其中包含：

- **文件校验信息**标题。
- **MD5**：文件的 MD5 哈希值。
- **CRC32**：文件的 CRC32 校验值。
- **SHA256**：文件的 SHA256 哈希值。
- **验证码输入框**：请输入下方验证码以继续下载。
- **验证码图片**：点击可刷新验证码。
- **确认下载**：绿色按钮，点击后开始下载。

> **建议**：
>
> - 下载完成后，可使用 MD5、CRC32 或 SHA256 校验工具核对文件完整性。
> - 若校验值与页面显示不一致，说明文件可能损坏或被篡改，请勿使用并重新下载。

# 资源包预览

资源包预览页面用于查看资源包内所有物品与方块在游戏中的外观。

![资源包预览](https://img.mcresource.cn/help/jpg_20261006_161715.jpg)

## 页面概述

- 页面顶部显示资源包名称与物品总数。
- 右上角提供 `返回详情页` 按钮。
- 顶部提示“版权说明：本页面展示的资源包预览内容仅供浏览参考，所有图片及资源版权归原作者所有。请勿用于商业用途或未经授权的分发。”

## 搜索与分类

- **搜索框**：可按中文名或注册名搜索。
- **分类切换**：
  - `按首段分类`：按注册名中第一个 `_` 前的部分分类（如 `minecraft:black_wool` → `black`）。
  - `按末段分类`：按注册名中最后一个 `_` 后的部分分类（如 `minecraft:black_wool` → `wool`）。
- **物品总数**：显示当前分类下的物品数量。
- **清空**：清除搜索条件。

## 查看与预览

页面提供多个分类，每个分类下包含多个物品，点击可切换当前查看的物品。

### 物品对比

页面中央以对比滑块形式展示物品在“资源包”与“原版”下的外观差异：

- 左侧为资源包效果，右侧为原版效果。
- 拖动中间滑块可对比两侧差异。
- 下方显示物品名称与注册名。

### 悬停提示

若鼠标悬停某个物品或方块，则会显示其在 Minecraft 中的注册名。

# 编辑历史对比

编辑历史对比页面用于查看同一资源的历次修改记录，并可选择任意两个版本进行对比。

![版本](https://img.mcresource.cn/help/-1_20261006_133743.jpg)

## 页面概述

- 页面顶部显示资源名称与 ID，右上角提供 `返回详情` 按钮与 `对比选中` 按钮。
- 中间为编辑记录列表，包含以下列：
  - **选择**：勾选框，用于选择要对比的版本。
  - **编辑者**：修改者名称，部分带有“最新”标签。
  - **时间**：修改时间与相对时间。
  - **改动说明**：本次修改的简要说明，无说明时显示“（无改动说明）”。
- 页面底部提示“请勾选两个版本进行对比（可选择任意两个版本）”。

## 版本对比页

勾选两个版本后点击 `对比选中`，进入版本对比页。

![对比](https://img.mcresource.cn/help/-2_20261006_133755.jpg)

版本对比页以左右两栏形式展示两个版本的字段差异：

- **版本 A**：标记为“较新”。
- **版本 B**：标记为“较旧”。
- 每栏顶部显示修改时间、编辑者与改动说明。
- 下方按字段逐项对比。
- 有差异的字段会以高亮方式标出。
