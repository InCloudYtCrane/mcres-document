# 关于本页的说明

本页主要介绍在主站内查找资源的方式，关于访问资源内容和获取资源请参阅[详情与下载](/10-主站/30-查找资源/20-详情与下载)。

## 名词辨析

本页涉及两个核心概念，此处先做辨析：

- **浏览**：没有明确目标，以探索和发现为目的查看资源。你翻看推送、分类网格、资源列表，看到感兴趣的再点进去。
- **检索**：带有明确目标，以精准定位为目的查找资源。你使用搜索框、筛选器和排序条件，快速缩小范围找到所需资源。

简单来说，浏览是“随便看看”，检索是“我要找某个东西”。

# 资源分类

## 三大资源类型

工坊主站收录以下三类资源：

- 资源包
- 光影包
- 地图

## 父分类与子分类

工坊对资源采用**双极交叉分类**方式：

- **一级分类（父分类）**：即三大资源类型，是资源最基础的归属。
- **二级分类（子分类）**：在父分类基础上，按类型、平台、版本、状态等多种维度进一步划分，各维度之间会产生交叉。

# 浏览资源

在工坊主站，可以通过多种方式浏览资源。

## 随便看看

如果你没有明确目标，可以从以下入口开始：

- **推送横幅区**：主页顶部的“热门”“轮播”“最新”三栏，展示当前主推资源。参见[主页与导航](/10-主站/10-开始使用/10-主页与导航)的[#推送横幅区](/10-主站/10-开始使用/10-主页与导航#_6)。
- **资源分类展示区**：主页按资源包、光影包、地图三大类横向排列的资源卡片网格。参见[主页与导航](/10-主站/10-开始使用/10-主页与导航)的[#资源分类展示区](/10-主站/10-开始使用/10-主页与导航#_8)。

## 浏览特定类型

如果你只关注某一类资源，可以：

- 在主页对应的[资源分类展示区](https://www.mcresource.cn/#section-resourcepack)浏览。
- 进入专门的资源列表页浏览：[资源包](https://www.mcresource.cn/resourcepacks)、[光影包](https://www.mcresource.cn/shaderpacks)、[地图](https://www.mcresource.cn/maps)。

资源列表页的详细说明见*资源列表页*。

## 从搜索结果浏览

在搜索结果页中，会推荐与搜索关键词匹配的资源，可以再此浏览。详见*搜索结果页*。

# 资源列表页

## 页面概述

资源列表页是方块工坊主站的核心功能页面，用于集中展示平台收录的 Minecraft 资源，包括[资源包](https://www.mcresource.cn/resourcepacks)、[光影包](https://www.mcresource.cn/shaderpacks)、[地图](https://www.mcresource.cn/maps)。你可以通过搜索、筛选、排序等方式快速找到所需资源，也可以通过右上角按钮向平台投稿。

![仿真资源界面](https://img.mcresource.cn/help/jpg_20261004_161948.jpg)
<div style="text-align:center; font-size:0.85em; color:#666; margin-top:6px;">该界面为仿真界面，将三个界面合并以节省版面，非实际截图，请以实际为准</div>

整个页面分为**顶部导航与操作区**、**左侧筛选侧边栏**、**右侧资源网格区**和**底部分页**四大板块。

## 顶部导航与操作区

### 全局导航栏

页面最上方是全局导航栏：

- **左侧 Logo**：方块工坊，点击返回主站首页。
- **分类菜单**：`主站`、`选料`、`茶室`，点击可切换至对应独立模块。
- **中间搜索框**：输入关键词，可对全站资源进行搜索。
- **右侧图标**：
  - `✉︎` 图标：进入站内消息中心。
  - `头像 + 用户名`：悬停弹出用户菜单，点击进入个人主页。

### 页面标题与分类切换

- 页面标题处显示当前分类：`资源包`、`光影包`或`地图`。
- 鼠标悬停全局导航栏 `主站`，在弹出菜单中点击相应选项进行分类切换。

### 排序与投稿

- **排序选项**：`最新`、`热门`、`名称`。点击可切换资源排列顺序。
- **投稿**：右上角绿色、黄色或蓝色按钮 `+ 添加XXX`，点击进入资源投稿页面。

### 快捷搜索栏

页面标题下方设有专用搜索框，输入关键词后点击 `搜索` 按钮，即可进入搜索页面并在当前分类下精准查找资源。

## 左侧筛选侧边栏

侧边栏用于精细化筛选资源，帮助你从海量数据中快速定位目标。

- **应用筛选**：设置好筛选条件后点击即可生效。
- **重置**：灰色按钮，一键清空所有已勾选的筛选条件。
- **筛选维度**：下方多选按钮，用于设置筛选条件。

> **建议**：如果你有明确的游戏版本和平台要求，建议优先勾选“平台”和“MC 版本”，再通过“状态”过滤出仍在维护的资源，能大幅提升查找效率。

## 右侧资源网格区

这是页面的主体内容区，以卡片网格形式展示资源。每张资源卡片包含以下信息：

- **预览图**：资源的高清缩略图。
- **资源名称**：如 `L_Ender's Cataclysm Old Music`、`Zenith's LUT Shader`、`怪物塔罗牌`、`Optimum Realism` 等。
- **资源简介**：一句话描述资源核心功能或特色。
- **分类/标签**：如 `模组专用`、`原版增强`、`PVP`、`写实`、`教育`、`机械` 等。
- **作者信息**：显示作者头像和名称。

点击任意资源卡片，即可进入该资源的详情页，查看完整介绍、预览效果并进行下载。

## 分页导航

页面底部提供分页控件，包含：

- **上一页/下一页按钮**（`<` / `>`）：点击切换至上一页或下一页。
- **页码列表**：紧挨着 `>` 按钮的页码为最后一页，点击跳转至对应页码。
- **跳转功能**：输入目标页码后点击 `跳转` 按钮，可快速跳转至指定页。

# 搜索结果页

## 页面概述

[搜索结果页](https://www.mcresource.cn/search)是方块工坊主站的全局检索中心。当你在主站中任意搜索框内输入关键词并确认后，系统会跳转至此页面。它不仅展示匹配到的**资源**（资源包、光影包、地图），还会展示匹配到的**用户**。搜索时不区分大小写。通过高级参数，你还可以精细调节搜索算法的严格程度与结果排序。

## 顶部导航栏

与资源列表页相同，不再赘述。

## 搜索区域

### 主搜索栏

页面顶部居中位置是搜索主界面，包含：

- **搜索图标**：提示当前处于搜索状态。
- **搜索输入框**：显示当前关键词，可在此修改搜索词。
- **搜索按钮**：输入完成后点击此按钮重新检索。

### 高级参数

搜索栏下方设有可折叠的 `高级参数` 区域，展开后可调节两个关键参数。

#### 相似度阈值（Similarity Threshold）

- **作用**：控制搜索结果的严格程度。值越高，只有拼写非常相似的结果才会被算作模糊匹配。
- **推荐区间**：0.70 - 0.85。
- **使用建议**：如果你拼写正确但结果太少，可适当降低此值（如 0.75），放宽匹配范围。

#### 模糊权重（Fuzzy Weight）

- **作用**：控制模糊匹配结果在排序中的优先级。值越高，拼写近似的结果越容易排在前面。
- **推荐区间**：0.30 - 0.70。
- **使用建议**：如果你搜索的词可能拼错，希望优先看到近似结果，可调高此值；如果希望精准匹配优先，可调低此值。

> **提示**：调节滑块后，无需手动点击“搜索”，系统通常会自动刷新结果，并在下方显示当前的阈值与权重状态。

## 分类筛选标签

搜索栏下方提供分类标签，用于筛选结果类型：

| 标签 | 说明 |
| :---: | :--- |
| **全部** | 展示所有类型的结果（用户、资源包、光影、地图） |
| **用户** | 仅展示匹配的用户账号 |
| **资源包** | 仅展示匹配的资源包 |
| **光影** | 仅展示匹配的光影包 |
| **地图** | 仅展示匹配的地图 |

点击任意标签，即可在当前搜索结果中按类型过滤。

## 结果统计与列表

### 结果统计

在分类标签下方，显示本次搜索的统计信息，包括“结果总数”与“当前参数”。

### 搜索结果列表

搜索结果以卡片列表形式纵向排列，不同类型的结果卡片结构略有不同。

#### 资源类结果（地图 / 光影包 / 资源包）

- **缩略图**：资源预览图。
- **类型标签**：地图（蓝色）、光影包（黄色）、资源包（绿色）。
- **资源标题**：如 `3D Minecraft in Minecraft`、`[DMS] Depth Map Shaders`。
- **分类标签**：如“机械”、“风格化”、“原版增强”。
- **简介**：资源的简短描述。
- **内容**：被截断的资源的具体内容。
- **关键词高亮**：搜索词在标题和简介中会以**黄色背景高亮**显示。

#### 用户类结果

- **头像**：用户的个人形象。
- **类型标签**：用户（紫色）。
- **用户名**：如 `MCRES-方块工坊`。
- **个性签名**：如“这里是MCRES · 官方账号~”。
- **角色**：主站用户组标签，如“工坊主管”。
- **关键词高亮**：搜索词在标题和简介中会以**黄色背景高亮**显示。

点击任意结果卡片，即可进入对应的资源详情页或个人主页。
