# 关于本页的说明

本页主要介绍主站账号的注册、登录、退出、登录状态与常见异常处理。

- **适用范围**：注册、登录、退出、登录状态、登录异常。
- **不涉及**：个人资料修改、密码修改、头衔佩戴、消息中心等，请查阅[用户中心](/10-主站/20-用户中心)相关文档。

# 账号有什么用处

工坊的账号是使用主站各项功能的基础，但并非所有功能都需要账号。

| 不需要账号 | 需要账号 |
| :---: | :---: |
| 浏览资源 | 投稿资源 |
| 查看资源详情 | 查看消息 |
| 查看别人的个人中心 | 进入个人中心 |
| 下载资源 | 发表看法 |

> **提示**：即使不注册账号，你也可以自由浏览和下载主站的资源。账号主要为你提供投稿、互动和个性化功能。

# 选择登录方式

工坊提供两种登录方式：**邮箱登录**和 **第三方登录**。

> **重要**：两种方式只能**任选其一**。一旦注册，**无法更换**。请根据自身情况谨慎选择。

- **邮箱登录**：需要设置并记住密码，支持通过邮箱找回密码。
- **第三方登录**：无需密码，通过第三方授权快速登录。

# 忘记密码与重置

> **注意**：只有通过邮箱登录才需要密码，通过第三方登录无需密码。

在登录界面点击登录卡片的右下角 `忘记密码？`，按提示操作即可。

# 退出登录

鼠标悬停在用户头像，在弹出菜单中点击 `退出登录`。

# 多设备登录

工坊支持多设备登录，用户有权益控制当前账号是否允许多设备登录，详情参见[账号设置](/10-主站/20-用户中心/20-账号设置)。

# 注销账号

目前工坊暂不支持账号注销服务，请期待后续更新喵~

# 账号异常状态

当账号被封禁时，其不再享有登录的权益，也不再享有账号的权益。
