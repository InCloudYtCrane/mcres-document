# 这是什么

这是[主站的主页，也是工坊的主页](https://www.mcresource.cn/)。

![主页截图](https://img.mcresource.cn/help/10-10-2026_205124_www.mcresource.cn_20261010_205604.jpg)

本页介绍主站主页的整体布局与各区域的主要功能，帮助你快速了解首页结构并找到所需入口。

## 主页整体布局

方块工坊主站主页采用深色主题，整体结构自上而下清晰分为以下几个主要区域：

1. **导航栏与工具栏**：Logo、分类菜单、搜索、用户入口。
2. **推送横幅区**：主推资源大图轮播，展示“热门”“轮播”“最新”三栏内容。
3. **公告与动态区**：近期维护通知与模块动态。
4. **资源分类展示区**：按类别横向排列的资源卡片网格。
5. **底部页脚**：版权与站点信息。

以下按页面从上到下的顺序，对各区域主要功能进行说明。

# 导航栏与工具栏

页面最上方是深色的全局导航栏，是访问各功能板块的核心入口。

## 全局导航栏

- **左侧 Logo**：方块工坊，点击返回主站首页。
- **分类菜单**：`主站`、`选料`、`茶室`，点击可切换至对应独立模块。
- **中间搜索框**：输入关键词，可对全站资源进行搜索。
- **右侧图标**：
  - `✉︎` 图标：进入站内消息中心。
  - `头像 + 用户名`：悬停弹出用户菜单，点击进入个人主页。

## 主页导航栏与工具栏

- **顶部工具栏**：位于页面顶部，包含常用工具入口：
  - 其中央的**搜索框**在处于焦点时会展示建议栏，建议栏中所展示的条目为根据你输入内容**自动补全的建议**。
  - 右侧的 `⊕资源包`、`⊕光影包`、`⊕地图` 是资源投稿的入口。
- **侧边导航栏**：页面旁侧是不随屏幕滚动的主页导航栏，是访问资源分类展示区内资源的快速方法：
  - **左侧导航菜单**：包含三个父分类入口，点击即可跳转至相应位置。
  - **右侧导航菜单**：包含多个子分类入口，点击即可跳转至相应位置。

> **提示**：侧边导航栏仅在主页内有效，用于快速定位到资源分类展示区的对应分类，不会跳转至独立页面。

# 推送横幅区

位于导航栏下方，占据页面最显眼的位置，使用三栏“热门”“轮播”“最新”展示，用于展示当前主推的优质资源。

- **热门**：当前热度较高的资源。
- **轮播**：主推资源大图轮播展示。
- **最新**：最近收录的资源。

点击相应资源即可跳转至对应界面。

# 公告与动态区

焦点横幅下方是公告与动态区，用于展示近期维护通知与模块动态。

- **公告**：站内维护、规则更新、活动信息、模块通知等。
- **动态**：主要展示工坊用户的登录、注册信息。

# 资源分类展示区

这是主页最主要的区域，也是占据篇幅最大的主体区域，采用“分类标题 + 资源卡片网格”的布局，方便按类型浏览资源。

- 点击任意卡片，即可进入该资源的详情页，查看完整介绍、预览效果并进行下载。
- 点击父分类右侧的 `更多 →` 链接，可进入该分类的完整列表页，查看更多资源。

资源分类展示区按**资源包**、**光影包**、**地图**三大类，每类下方展示若干资源卡片。

# 底部页脚

页面最底部为页脚区域，包含：

- 版权信息
- 站点相关链接
- 快速链接
- 关注方式与联系方式
