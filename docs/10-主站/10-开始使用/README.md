# 开始使用

本目录帮助新用户快速了解主站的基本使用方式，包括主页结构与账号相关操作。

## 本目录包含

- [主页与导航](/10-主站/10-开始使用/10-主页与导航)：介绍主站主页的整体布局、导航栏与工具栏、推送横幅区、公告与动态区、资源分类展示区及底部页脚。
- [账号与登录](/10-主站/10-开始使用/20-账号与登录)：介绍账号的用途、注册、登录、退出、多设备登录、忘记密码与重置、注销及账号异常状态。

## 推荐阅读顺序

1. 先阅读[主页与导航](/10-主站/10-开始使用/10-主页与导航)，了解主站主页结构与各功能入口的位置。
2. 再阅读[账号与登录](/10-主站/10-开始使用/20-账号与登录)，了解如何注册、登录以及账号相关操作。

## 快速开始

如果你是第一次来到方块工坊，可以按以下步骤开始：

1. 打开主站：<https://www.mcresource.cn/>
2. 浏览首页推送与资源分类，找到感兴趣的资源。
3. 如需投稿、查看消息或进入个人中心，请先注册并登录账号。
4. 遇到问题可查阅[常见问题](/10-主站/100-关于/30-常见问题)或[问题反馈](/10-主站/50-站内公告与反馈/20-问题反馈)。

## 与其它模块的关系

- 本目录仅涵盖主站的基本上手内容。
- 更详细的资源浏览、投稿、用户中心等功能，请查阅对应目录。
- 选料、茶室等独立模块不在本目录范围，请查阅各自帮助文档。
