# 关于本页的说明

本页介绍资源投稿的入口、发布流程，以及各类资源发布页面的导航结构。

关于表单字段的具体填写规范、富文本编辑器使用说明、高级操作、扩展信息与资源特有字段，请参阅[表单字段与填写指南](40-表单字段与填写指南)。本页不再重复说明。

关于已发布资源的修改，请参阅[编辑资源](20-编辑资源)。关于提交后的审核流程与状态查看，请参阅[审核与状态](30-审核与状态)。

# 投稿入口

- **发布资源**：在主页工具栏点击 `⊕资源包`、`⊕光影包`、`⊕地图`，或在资源列表页点击右上角 `+ 添加资源包`、`+ 添加光影包`、`+ 添加地图` 按钮，即可进入对应的发布页面。
- **发布预设**：在光影包详情页显示，点击 `👁︎ 查看预设`，进入光影包预设页面，然后点击右上角 `⊕投稿预设` 按钮，即可进入对应的发布页面。

发布页面要求处于登录状态。若未登录，将被引导至登录界面。

# 发布流程

1. 登录主站账号。
2. 通过投稿入口进入对应的发布页面。
3. 按左侧导航依次填写：基本信息、兼容信息（资源包为“兼容信息”，光影包为“兼容与引擎”，地图为“兼容与要求”，预设为“配置详情”）、作者与下载（预设没有这一项）、扩展信息（预设没有这一项）。
4. 如有需要，在左侧下方“传话筒”中给审核员留言（若用户拥有免审核权限则不显示“传话筒”）。
5. 在“改动说明”中简要描述本次发布的内容（可选，但建议填写）。
6. 点击底部提交按钮，等待审核。

> **权限提示**：如果您拥有免审核权限，页面顶部会显示您的角色与“拥有免审核提交/编辑权限”的提示。该提示在发布和编辑页面均会出现。

# 发布页面导航结构

三类资源（资源包、光影包、地图）和预设（光影包预设）的发布页面均采用左侧导航 + 右侧表单的布局，步骤基本一致，但各步骤名称与特有字段有所不同。

- **资源包**：基本信息、兼容信息、作者与下载、扩展信息。
- **光影包**：基本信息、兼容与引擎、作者与下载、扩展信息。
- **地图**：基本信息、兼容与要求、作者与下载、扩展信息。
- **光影包预设**：基本信息、配置文件代码。

各步骤中的具体字段填写规范请参阅[表单字段与填写指南](40-表单字段与填写指南)。

# 发布相关常见问题

**Q：发布资源后多久能通过审核？**
A：审核时间以站内公告或管理说明为准，请耐心等待。详见[审核与状态](30-审核与状态)。

**Q：提交后还能修改吗？**
A：可以。审核通过后，可在资源详情页点击“编辑此页面”进行修改。详见[编辑资源](20-编辑资源)。

**Q：发布时必须填写“改动说明”吗？**
A：发布新资源时“改动说明”为可选，但建议简要描述本次发布的内容，方便审核员了解。

**Q：可以发布多个资源吗？**
A：可以。每次提交只对应一个资源或一个预设，如需发布多个，请分别提交。
