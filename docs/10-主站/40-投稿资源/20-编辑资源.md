# 关于本页的说明

本页介绍已发布资源的编辑方式、编辑历史对比，以及与发布流程的差异。

关于表单字段的具体填写规范、富文本编辑器使用说明、高级操作与扩展信息填写说明，请参阅[表单字段与填写指南](40-表单字段与填写指南)。本页不再重复说明。

关于提交后的审核流程与状态查看，请参阅[审核与状态](30-审核与状态)。

# 编辑入口

- **从资源详情页进入**：在资源详情页顶部点击 `编辑此页面` 按钮，即可进入该资源的编辑界面。
- **从光影包预设进入**：在光影包预设详情页点击 `编辑预设` 按钮，进入预设编辑界面。

编辑页面要求处于登录状态。若未登录，将被引导至登录界面。

# 编辑界面概述

编辑界面采用左侧导航 + 右侧表单的布局，与发布页面高度相似，但存在以下区别：

- **顶部提示**：显示“您正在编辑：[资源名称] (ID: [资源ID])”，明确当前编辑的对象。
- **提交按钮**：底部按钮显示为 `更新资源包`、`更新光影包`、`更新地图` 或 `更新预设`，而非发布页面的“提交”按钮。

# 编辑流程

1. 从编辑入口进入对应的编辑界面。
2. 按左侧导航依次修改需要更新的字段：基本信息、兼容信息（资源包为“兼容信息”，光影包为“兼容与引擎”，地图为“兼容与要求”，预设为“配置详情”）、作者与下载（预设没有这一项）、扩展信息（预设没有这一项）。
3. 在“改动说明”中简要描述本次修改的内容。
4. 如有需要，在“传话筒”中给审核员留言（若用户拥有免审核权限则不显示“传话筒”）。
5. 点击底部更新按钮，提交修改。

# 编辑与发布的差异

| 对比项 | 发布资源 | 编辑资源 |
| :---: | :--- | :--- |
| 入口 | 主页工具栏 `⊕资源包` 等，资源列表页 `+ 添加XXX`，或光影包预设页 `⊕投稿预设` | 资源详情页 `编辑此页面` |
| 顶部提示 | 无特殊提示 | “您正在编辑：[资源名称] (ID: [ID])” |
| 提交按钮 | `提交资源包` / `提交光影包` / `提交地图` | `更新资源包` / `更新光影包` / `更新地图` |

# 编辑相关常见问题

**Q：编辑后需要重新审核吗？**
A：如果您拥有免审核权限，编辑后直接生效；否则需要重新进入审核队列。详见[审核与状态](30-审核与状态.md)。

**Q：可以回退到历史版本吗？**
A：目前不支持一键回退，但可以通过编辑历史查看旧版本的内容，手动修改为新版本。

**Q：资源详情页的“编辑历史对比”按钮是什么？可以在此编辑吗？**
A：编辑历史对比页面用于查看同一资源的历次修改记录，并可选择任意两个版本进行对比，并没有编辑功能。

**Q：编辑后审核不通过怎么办？**
A：审核不通过时，会根据驳回原因指出问题所在。请根据原因修改后重新提交。

**Q：编辑光影包预设时，为什么顶部显示“编辑模式”？**
A：“编辑模式”是预设编辑界面的标识，表示您正在修改一个已有的预设，而非创建新预设。
