# 用户中心

本目录介绍主站用户中心的相关功能，包括个人主页、账号设置与消息中心。

## 本目录包含

- [个人主页](/10-主站/20-用户中心/10-个人主页)：介绍个人主页的页面布局、进入方式、左侧菜单栏与右侧主内容区。
- [账号设置](/10-主站/20-用户中心/20-账号设置)：介绍账号信息、通知设置与隐私设置的修改方式。
- [消息中心](/10-主站/20-用户中心/30-消息中心)：介绍消息中心的作用与进入方式。

## 推荐阅读顺序

1. 先阅读[个人主页](/10-主站/20-用户中心/10-个人主页)，了解个人主页的结构与功能。
2. 再阅读[账号设置](/10-主站/20-用户中心/20-账号设置)，了解如何管理账号信息、通知与隐私。
3. 最后阅读[消息中心](/10-主站/20-用户中心/30-消息中心)，了解如何查看互动记录与系统通知。

## 快速开始

- 登录主站后，点击右上角头像即可进入个人主页。
- 在头像弹出菜单中点击 `账号设置` 可管理账号信息。
- 点击右上角小信封图标 `✉︎` 可进入消息中心。

## 与其它模块的关系

- 用户中心的功能需要登录后才能使用。
- 账号的注册、登录、退出等操作请查阅[账号与登录](/10-主站/10-开始使用/20-账号与登录)。
- 选料、茶室等独立模块不在本目录范围，请查阅各自帮助文档。
