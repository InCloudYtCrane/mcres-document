# 页面概述

个人主页是方块工坊用户展示个人资料、管理个人内容、查看社区贡献的核心页面。登录后点击右上角头像即可进入自己的个人主页，点击他人用户名或头像也可访问其公开主页。

| 看自己的个人主页 | 看别人的个人主页 |
| :---: | :---: |
| ![看自己](https://img.mcresource.cn/help/jpg_20260928_221500.jpg) | ![看别人](https://img.mcresource.cn/help/jpg_20260928_222448.jpg) |

整个页面分为**左侧菜单栏**（个人资料与导航）和**右侧主内容区**（动态与数据）两大部分。

# 如何进入

## 进入自己的个人主页

- **方式一**：直接点击右上角的用户头像。
- **方式二**：
  1. 鼠标悬停在用户头像；
  2. 在菜单中点击 `我的主页`。

> <details><summary>点击查看图解</summary><img src="https://img.mcresource.cn/help/jpg_20260928_224359.jpg" alt="个人中心进入方式图解" style="max-width: 100%;"></details>

## 进入别人的个人主页

- 在任何地方点击别人的头像或带有超链接的昵称即可进入。
- 在浏览器地址栏输入 `https://www.mcresource.cn/profile/<id>`，其中 `<id>` 替换为具体用户的 id，例如 <https://www.mcresource.cn/profile/3>。这种方法同样适用于进入自己的个人主页。

# 左侧菜单栏

左侧菜单栏是个人主页的身份核心区，自上而下包含以下内容。

## 个人资料

### 头像与头衔徽章

- **头像**：用户的个人形象展示。左上角带有绿色或灰色圆点，表示当前在线或离线状态。
- **头衔徽章**：头像下方展示已获得的头衔。
  > **提示**：头衔是通过活动获取的。
- **设置图标（齿轮）**：点击可进入账号设置，修改个人资料、头像、密码等。

### 昵称与用户组标签

- **昵称**：头衔徽章下方。
- **用户组标签**：昵称下方，标明用户所在的用户组。用户组与用户的权限有关，详见[管理中心-角色与权限](/40-管理中心/20-角色与权限)。

### 个人简介与基础信息

- **签名**：展示用户签名。
- **操作按钮**：`转到茶室主页`，一键跳转至该用户在茶室模块的个人主页。
- **ID**：用户的唯一数字标识。
- **入驻于**：注册时间。
- **状态**：在线或离线。

### 数据统计卡片

展示用户在平台的核心数据，以四宫格形式呈现：

| 指标 | 说明 |
| :---: | :---: |
| **编辑** | 用户在资源页面的编辑次数 |
| **看法** | 用户发表的评论或观点数量 |
| **信誉** | 用户在平台的信用分值 |
| **砖块** | 平台内的虚拟积分，属于成就 |

## 导航菜单

侧边栏下方提供以下快捷导航入口，方便管理个人内容或查看他人内容：

- **我的主页 / TA的主页**：展示和查看茶室动态与编辑动态。
- **我的作品 / TA的作品**：展示和查看创作的作品。
- **我赞过的 / TA赞过的**：展示和查看点过赞的资源。
- **我收藏的 / TA收藏的**：展示、分类和查看自己收藏过的资源，或查看他人收藏过的资源。
- **贡献日历**：展示和查看在工坊的编辑动态。
- **我的成就 / TA的成就**：展示、完成和查看自己的任务与成就，或查看他人的成就。
- **留言板**：发表留言、查看留言、回复留言以及编辑留言。

# 右侧主内容区

右侧占据大部分面积的是主内容区，展示在导航菜单中选中的板块。
